# 0.12.0 — 2026-10-28

## Added

- **Weather guide resource:** Add the nws-weather-guide skill as an MCP resource for reconciling forecasts, alerts, observations, and forecaster discussions. The guide also ships in plugin installs, npm, Docker, and MCPB bundles.
- **Agent Plugins metadata:** Root `plugin.json` and `mcp.json` provide plugin discovery alongside the Claude Code and Codex overlays.

## Changed

- **Enrichment text:** String values such as station IDs, filters, and continuation cursors render as code literals through the framework update.
- **Development tooling:** Sync framework guides, packaging validation, and the bug report environment table; shorten installation instructions and document Docker execution.
- **Dependency installation:** Set the minimum release age to one day.

## Fixed

- **MCPB cleanup:** Preserve executable SDK skill modules while removing dependency agent documentation, node-gyp build output, and build-only files ([mcp-ts-core #794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
