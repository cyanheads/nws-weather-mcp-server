# 0.12.1 — 2026-11-11

## Added

- **`nws_search_alerts` window search** ([#81](https://github.com/cyanheads/nws-weather-mcp-server/issues/81)): `start` and `end` return the alert messages issued in that window within NWS's 7-day retention, updates and cancellations included, paged by a tool-side keyset `cursor` over `sent`. Adds a `window` output field and notices for retention (messages before the cutoff may be missing), empty windows, and walks that cannot page past a tie.
- **`message_type`** (`Alert`, `Update`, `Cancel`) on `nws_search_alerts`, for active and window searches.
- **`seaLevelPressurePa`** on `nws_get_observations` and `nws_get_observation_history` ([#80](https://github.com/cyanheads/nws-weather-mcp-server/issues/80)): null on 5-minute records, which carry no `SLP` remark.
- **Expiry notice** on `nws_get_office_discussion` when every UGC segment returned is past its expiry ([#79](https://github.com/cyanheads/nws-weather-mcp-server/issues/79)); on SPS it points to `nws_search_alerts`.

## Changed

- **`event` filter** on `nws_search_alerts` resolves terms against `/alerts/types`; an unusable `/alerts/types` body fails as an upstream error instead of reporting that no type matches.
- **`barometricPressurePa`** is described as the altimeter setting; observations render separate Altimeter and Sea-Level Pressure lines, and history gets one column for each ([#80](https://github.com/cyanheads/nws-weather-mcp-server/issues/80)).
- **`marine_forecast_unsupported`** on `nws_get_forecast` points to `nws_get_zone_forecast` and names the zone families that carry a text forecast; the gridless message names an offshore zone ([#82](https://github.com/cyanheads/nws-weather-mcp-server/issues/82)).
- **Date-time inputs** on `nws_get_observation_history` and `nws_search_alerts` accept lowercase `t`/`z` and offsets without a colon, sent upstream in canonical form.
- **Invalid-cursor recovery hints** on `nws_find_stations`, `nws_get_forecast`, `nws_get_observation_history`, and `nws_search_alerts` are plain text, with the parameter names as code spans in `content[]`.
- **`no_products`** message for SPS and HWO says what is on file rather than implying none is active.
- **`limit`** no longer has a 10000 ceiling on `nws_find_stations`, `nws_get_observation_history`, and `nws_search_alerts`.
- **Server `instructions`** and the `nws-weather-guide` skill (1.1) cover recent alerts, past-warning questions, expired statements, and the altimeter/sea-level split.
- **Timestamps rendered without a zone** (every alert row) reuse one date formatter; output is unchanged.
- **Framework sync:** skills, scripts, and the changelog template follow `@cyanheads/mcp-ts-core` 0.13.22.

## Fixed

- **`nws_get_zone_forecast` `updated`** is corrected when NWS misreads the 12 o'clock hour of the ZFP header, with a `notice` naming NWS's value ([#78](https://github.com/cyanheads/nws-weather-mcp-server/issues/78)).
- **inHg values** always show two decimals (`29.90`, not `29.9`).
- **Network failure** that outlives the retries is ServiceUnavailable instead of InternalError.
