# 0.11.2 — 2026-10-24

## Changed

- **`nws_get_forecast` `include_amounts`** adds every native precipitation, snowfall, and ice accumulation interval, preserving units, nulls, and the separate grid update time; unavailable amounts leave the main forecast available with a notice ([#75](https://github.com/cyanheads/nws-weather-mcp-server/issues/75)).
- **Upstream inline text** renders literally in Markdown responses, preserving punctuation in station names, forecasts, alert fields, and office outlines.
- **Hosted-client examples** use each client's configuration shape; development guidance and audit attribution track the adopted framework.

## Fixed

- **`nws_get_observations` limited-data notice** reaches both response surfaces once, composed with staleness guidance, while preserving missing measurements and measured zeroes ([#73](https://github.com/cyanheads/nws-weather-mcp-server/issues/73)).
- **`nws_find_stations` cursors** reject fractional or non-finite windows before lookup and treat whitespace-only cursors as the first page; valid legacy tokens retain their paging behavior ([#74](https://github.com/cyanheads/nws-weather-mcp-server/issues/74)).
