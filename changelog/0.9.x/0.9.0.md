# 0.9.0 — 2026-08-13

## Changed

- **Paging counts** on `nws_get_forecast`, `nws_find_stations`, and `nws_search_alerts` unify on `totalCount` (pre-limit total) and `shown` (this response) — replacing `totalFound`/`totalCount`, `periodCount`/`totalPeriodCount`, and `shownCount`. **Breaking:** `nws_find_stations.totalCount` keeps its name but flips meaning, from this page's count to the pre-limit total — the old value now lives in `shown`; retired field names are removed, not aliased, so a stale reference reads `undefined` rather than a silently wrong number. ([#35](https://github.com/cyanheads/nws-weather-mcp-server/issues/35))

## Fixed

- **`nws_search_alerts`** collapses alerts NWS returns more than once within a single `/alerts/active` fetch (byte-identical `id`, `sent`, `event`, `areaDesc`), keeping the first occurrence ahead of the event filter and page window. `totalCount` now counts distinct alerts. ([#36](https://github.com/cyanheads/nws-weather-mcp-server/issues/36))
