# 0.11.1 — 2026-10-23

## Added

- **Alert `office`, `vtec`, `nwsHeadline`, and `hazard`** ([#66](https://github.com/cyanheads/nws-weather-mcp-server/issues/66)) on `nws_search_alerts` and `nws_get_alert`. `office` is the code `nws_get_office_discussion` takes (null for tsunami centres and national tests); `hazard` holds the NWS hail, wind, tornado, and flash-flood tags that were sent.
- **Observation `precipitationLastHourMm`, `precipitationLast3HoursMm`, and `precipitationLast6HoursMm`** ([#65](https://github.com/cyanheads/nws-weather-mcp-server/issues/65)) on `nws_get_observations` and `nws_get_observation_history`. `0` is a METAR trace and renders `Trace`; `null` means no amount was reported.
- **`nws_get_forecast` `updateTime`** ([#68](https://github.com/cyanheads/nws-weather-mcp-server/issues/68)) — when the grid's data was last updated, beside `generatedAt`. A `notice` flags a grid not updated in more than 24 hours.
- **`nws_get_office_discussion` `product_type: "FWF"`** ([#67](https://github.com/cyanheads/nws-weather-mcp-server/issues/67)) — Fire Weather Planning Forecast, with the outline and `sections` selection by fire zone code. Fire-typed `affectedZones` now point to it from the alert output, `nws_get_zone_forecast`, and the server instructions.

## Fixed

- **`nws_search_alerts` and `nws_get_forecast` cursors carry their query** ([#63](https://github.com/cyanheads/nws-weather-mcp-server/issues/63), [#70](https://github.com/cyanheads/nws-weather-mcp-server/issues/70)) — the alert filters and the hourly or 7-day mode now travel in `nextCursor`, so sending it back alone resumes the same query; filter inputs and `hourly` are ignored on a continued page. 0.11.0 tokens still decode, and a malformed forecast cursor fails before any NWS request.
- **Alert `description` and `instruction`, and office `productText`, render in fenced `text` blocks in `content[]`** ([#71](https://github.com/cyanheads/nws-weather-mcp-server/issues/71), [#62](https://github.com/cyanheads/nws-weather-mcp-server/issues/62)) — a CommonMark client no longer reflows fixed-width tables or turns `* WHAT...` lines into lists. `structuredContent` is unchanged.
- **Observation text shows a gust when sustained speed is missing** ([#61](https://github.com/cyanheads/nws-weather-mcp-server/issues/61)) — `Wind` renders each reported component (`sustained not reported, gusts 27 mph (44 km/h)`) on both observation tools.
- **Observation `temperatureC`, `dewpointC`, `heatIndexC`, and `windChillC` keep one decimal** ([#64](https://github.com/cyanheads/nws-weather-mcp-server/issues/64)) — METAR tenths survive, and the °F in `content[]` derives from the shown value.
- **Unknown-office `no_products` message** ([#69](https://github.com/cyanheads/nws-weather-mcp-server/issues/69)) names `location.office` of `nws_get_forecast` output instead of a nonexistent `cwa` field.
